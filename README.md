## 📖 Deskripsi Proyek

**Planto.** adalah aplikasi web *e-commerce* modern yang dirancang khusus untuk memenuhi kebutuhan pecinta tanaman hias, dekorasi interior hijau (*urban jungle*), serta masyarakat urban yang membutuhkan tanaman penyaring udara alami (*air-purifying plants*) di rumah maupun lingkungan ruang kerja.

### 🎯 Latar Belakang & Tujuan
1. **Mendukung Gaya Hidup Sehat & Ramah Lingkungan**: Memudahkan masyarakat memilih dan membeli tanaman penyaring polusi serta penghasil oksigen murni (seperti *Monstera*, *Sansevieria*, dan tanaman meja) secara daring.
2. **Pengalaman Pengguna Interaktif & Estetik**: Menghadirkan antarmuka bertema *dark botanical aesthetic* (`#171f12`) yang elegan, nyaman dipandang (*eye-friendly*), dan memiliki performa tinggi berkat pemanfaatan teknologi frontend terkini.
3. **Edukasi & Panduan Perawatan Tanaman**: Setiap produk dilengkapi dengan deskripsi kegunaan, keunggulan pot estetik (terakota/keramik), hingga rekomendasi penempatan ruangan.

## ✨ Fitur-Fitur Utama Aplikasi

- 🍃 **Hero Landing Page**: Disertai headline interaktif, navigasi terstruktur, pencarian produk, indikator keranjang belanja dinamis, dan tombol login pengguna.
- 🎛️ **Navigasi Kategori Fleksibel**: Pengelompokan produk instan melalui filter tab:
  - *Semua Tanaman*
  - *Tanaman Indoor*
  - *Tanaman Meja*
  - *Tanaman O2 (Pembersih Udara)*
  - *Sukulen & Kaktus*
- 🪴 **Katalog Produk Dinamis**: Menampilkan foto resolusi tinggi, nama varietas, deskripsi bahan pot, harga terstandarisasi Rupiah (Rp), dan tombol *Quick Add to Cart*.
- 🌬️ **Interactive Carousel / Slider**: Menyorot koleksi unggulan tanaman penghasil O2 terbaik ruangan dengan navigasi slider (`< 01/04 >`).
- ⭐ **Testimoni Pelanggan**: Bagian ulasan pembeli terverifikasi dengan desain *glassmorphism card* dan rating bintang 5.
- 📩 **Footer & Sistem Langganan**: Formulir langganan newsletter terbaru, informasi ringkas perusahaan, navigasi tautan, dan integrasi media sosial.
- 📱 **Desain Sepenuhnya Responsif**: Nyaman diakses dari perangkat mobile (smartphone), tablet, maupun monitor desktop resolusi tinggi.

## 🚀 Panduan Menjalankan Proyek Secara Lokal

### Prasyarat Sistem
- [Node.js](https://nodejs.org/) versi `18.0.0` atau yang lebih tinggi
- Node Package Manager (`npm` / `yarn` / `pnpm`)

### Langkah Instalasi

1. **Clone repositori proyek:**
   ```bash
   git clone https://github.com/Azaleaaaaaaaaa/Planto.git
   cd Planto
   ```

2. **Install seluruh dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Buka peramban (*browser*) dan akses: **`http://localhost:5173`**.

4. **Build untuk tahap produksi:**
   ```bash
   npm run build
   ```
